# 本地视频保存

> 新上传改为私密 HLS 加密流程，启用前请按 [私密视频配置与使用](private-videos.md) 完成密钥、OSS 权限和跨域配置。旧公开 MP4 继续可用，不再为新视频生成公开 MP4。

入口：`/ops-7q4m/videos`，需要现有超级管理员登录。下载和 OSS 上传是独立的显式操作；文章编辑器可从视频库插入已上传的私密视频或旧公开 MP4。下载或上传本身不修改文章，不自动发布。

## 使用

1. 手动安装 FFmpeg（包含 ffprobe）。macOS 已配置 Homebrew 时执行 `brew install ffmpeg`；Linux 使用发行版官方软件源安装。保持 FFmpeg 更新。
2. 验证 `ffmpeg -version`、`ffprobe -version`。服务使用独立 PATH 时，在 `.env.local` 中填写 `VIDEO_FFMPEG_PATH` / `VIDEO_FFPROBE_PATH` 的可执行文件绝对路径，然后重启服务。启动脚本不安装依赖。
3. 在后台打开“本地视频保存”，安装 `/shenxiang-video-importer.user.js`。需要安装在能够运行 Tampermonkey 的浏览器中；Codex 内置浏览器不保证支持扩展。
4. 点击“生成配对码”。在来源网页点击“保存视频到本地”（或油猴菜单中的同名命令），输入视频序号、本地服务地址和配对码，确认有权保存后提交。
5. 回到后台查看进度，成功后预览或下载 MP4。也可以直接在后台手动填写有权保存的 HLS 地址。

### 最后一个分片损坏或下载失败

只有最后一个视频分片失败、且前面已有完整分片时，任务才可能显示「尾段失败 · 待确认」。程序保留此前分片，暂停自动备用线路重下，**不会自动生成缺失内容的视频**。

1. 在任务卡片点击「忽略失败尾段并合成」。确认框显示预计缺失秒数和保留时长。
2. 确认后进入原单任务队列，只读取并校验本地保留分片，不使用旧签名链接，不重新下载。合成后依然校验视频轨道和剩余时长。
3. 完成后标记「成功（缺少尾段）」；可预览、下载、手动上传 OSS。下载文件名包含 `-incomplete`，视频库和上传确认也显示缺失提示，插入正文的默认视频标题带「缺少尾段」。它不是完整原视频。
4. 不想保留时，点击「丢弃保留分片」并确认，释放空间。这个删除不能恢复；任务错误记录仍保留。

此入口只接受末尾分片的网络故障、404/410、部分服务端错误或可识别的内容损坏；中间分片、初始化段、唯一分片、密钥获取/解密错误、401/403、配额和任务取消仍失败，不允许跳过。独立音视频双清单暂不提供此入口，避免无声成品或音画长度不一致。

待确认分片保存在非公开任务目录，清单只含本地文件名，不保存远端签名 URL 或解密密钥；合成前重新检查文件大小、哈希和路径。待确认/合成失败任务在重启后仍保留，可再次确认；取消合成也保留分片，只有合成成功或明确丢弃后清理。等待确认也占用最多 12 个未完成任务的额度，需及时合成或主动丢弃。**更新前已经清理掉分片的历史失败任务无法恢复，需要从来源页面重新提交。**

接口：管理员同源 `POST /api/admin/video-imports/<UUID>/tail`，JSON `{ "action": "merge", "confirmed": true }` 或 `{ "action": "discard", "confirmed": true }`。配对码不能调用此接口。

## 上传 OSS 并插入文章

1. 在成功的视频任务上点击“加密上传 OSS”，确认有权向指定观看者提供视频后开始。也可在文章编辑器的“视频”窗口中上传。任务在服务端后台运行，接口立即返回，列表显示独立的上传进度、成功状态或失败原因。
2. 上传完成后打开 `/ops-7q4m/editor`，选择文章，把光标放到目标位置，点击富文本工具栏“视频”。选择已上传的视频并点击插入。尚未上传的视频只能本地预览，不能用管理员下载接口地址发布给访客。
3. 右侧预览可播放视频。插入不会自动保存，继续点击“保存草稿”或“发布内容”；修改已发布文章后需点击“发布更新”。每篇文章最多 20 个视频。一个已上传视频可被多篇文章复用。
4. 新视频正文保存私密资源 ID，旧公开 MP4 保留原 URL。发布文章不会重复上传视频；同步远端先登记私密资源和接收端专属的加密密钥包，再保存文章，不向远端发送明文 MP4。

上传保留原本地 MP4，不删除也不加入 Git。上传状态写入视频任务记录，与下载状态分开；上传失败不影响本地预览/下载，可以手动重试。服务重启会将中断的上传标为失败，不自动续传或发布；已登记完整资源可在校验后复用。已完成的私密任务若缺少资源数据库或主密钥，明确提示恢复备份或重新导入新任务，不覆盖旧资源。失败可能留下私有密文，清理前须核对有效引用。

新视频先在受限临时目录封装为加密 HLS，再逐个上传密文分片，单任务队列最多 12 个；单次 OSS 请求 60 秒超时，加密及上传总计最多 30 分钟，避免把整个视频读入内存。私有读权限和匿名拒绝校验完成后才显示 100%。管理页关闭后上传继续，需要服务进程持续运行；不要在上传中重启服务。

### 配置与访问权限

- 新加密上传默认关闭；按 [私密视频说明](private-videos.md) 在各部署生成独立密钥、配置私有 OSS 权限及 CORS，然后开启 `PRIVATE_VIDEO_UPLOAD_ENABLED`。
- 私密分片使用 Bucket 的标准 HTTPS 端点和独立 `PRIVATE_VIDEO_OSS_PREFIX`，不复用公开 CDN。远端播放服务需要该目录的 OSS 读取/签名权限。
- 旧公开 MP4 的 `OSS_PUBLIC_BASE_URL` / `OSS_ARTICLE_VIDEO_PREFIX` 配置仍需保留。旧地址不受访问码或定位交互保护，本次不会迁移旧对象或改变其 ACL。
- 播放器支持手动播放、暂停、拖动、全屏及移动端内联播放，不自动播放。新上传仅支持 H.264/AAC（或无音频），不自动转码；真实微信兼容性需要部署后验证。OSS 会产生存储和流量费用。

### 接口与内容安全

- 管理员 `GET /api/admin/video-imports` 返回任务、OSS 配置就绪状态和非敏感 `articleVideoBaseUrl`。
- 管理员同源 `POST /api/admin/video-imports/<UUID>/oss`，JSON `{ "authorized": true }`，只接受已完成的本地视频任务，不接收浏览器传入的文件路径或目标 Bucket。
- 草稿可保留尚未准备好的视频 HTML；正式发布、同步发送和接收时要求私密资源已登记，或使用原有合规的公开 OSS MP4。Blob、本地管理员接口、外站、临时签名地址，以及同时填写私密 ID 和公开 src 的节点都会被拒绝。
- 详情页只保留合规视频地址，强制显示播放控件、关闭自动播放、移除脚本/事件/任意嵌入。内容折叠时不可见的视频控件不可聚焦，并暂停被遮住的视频；原有定位与授权判定不变。

助手仅发送至本机 `localhost` / `127.0.0.1`，默认端口 3217。配对码有效 10 分钟，仅能提交一批 1–6 个任务，不能读取列表或下载成品。提交失败也可能消耗配对码，重新生成即可；超时先检查后台，避免重复提交。

## 能力和限制

- DPlayer 的 JSON `config.video.type=hls` 配置；主线路与不同域名备用线路。
- 完整 VOD HLS、最高 BANDWIDTH 变体、默认独立音轨、普通 TS / fMP4 分片（不含字节范围），支持无加密和标准 AES-128（`KEYFORMAT=identity`，省略时也为 identity）。
- AES-128 使用来源正常提供的 16 字节二进制密钥，按 CBC / PKCS#7 逐片解密；支持显式 IV、媒体序号隐式 IV、密钥轮换和 `METHOD=NONE` 切换。加密初始化段必须有显式 IV；主清单 SESSION-KEY 仅作为格式提示，具体分片仍以媒体清单 KEY 声明为准。
- 不支持直播、DRM / SAMPLE-AES / 非 identity 密钥格式、字节范围分片、LL-HLS、动态变量、额外字幕及多音轨选择；明确报错，不绕过限制。
- 不导出 Cookie，不伪造来源，不复制浏览器会话；仅浏览器可访问的资源不保证可下载。HTTP 401/403 停止，用户通过来源方正常授权流程取得新配置后重新提交。
- 逐任务、逐分片处理；队列最多 12 个，单批最多 6 个。单任务下载量 1 GiB，单分片 32 MiB，清单 1 MiB，最多 10000 个资源，点播最长 2 小时，总运行限时 30 分钟。每次下载分片前要求至少 2 GiB 可用空间。
- 临时网络错误最多重试 2 次；主线路持续网络异常或 404 可从备用线路重新开始，不混拼。认证 / 格式 / 配额失败不切换。
- 没有通用的网络断点续传。可确认忽略尾段的任务保留本地分片；其他失败或取消仍清理临时文件。正常服务重启后将运行中的任务标为失败，尾段合成任务可再次确认，其他旧临时目录可由管理员确认后清理。
- FFmpeg 只读取本地重写清单并复制音视频流封装为 MP4，不转码；ffprobe 检查视频轨道、指定音轨和时长（误差不大于 3 秒或 2%）。这是结构检查，不替代完整逐帧解码检查或人工预览。某些编码或设备不兼容时可能无法浏览器预览，即使文件封装成功。

## 存储与运行

`data/video-imports/<UUID>/result.json` 保存不含签名 URL 的状态，`video.mp4` 是成功成品，`work/` 是临时文件。整个目录已被 Git 忽略，不在 public 下；仅管理员文件接口可读取。成品不会自动删除，需定期检查磁盘并在停止服务后备份/归档。

“本地”指服务进程所在电脑，不是访问网页的手机；在远端启动服务时手动导入会保存到远端磁盘。来源网页助手只连接本机服务。

使用现有长期运行的 Node / Next 服务、单进程与持久磁盘；不适用于 Serverless、PM2 cluster 或多个服务共享同一目录。`process.lock` 防止多个进程管理同一任务目录；不要删除正在运行进程的锁。进程退出后的锁在下次启动检查时自动接管。热更新使用全局单例保留队列，部署重启不续传。

## 安全边界

- 管理员读取接口与同源写入检查；油猴提交使用独立一次性随机令牌，不传管理员 Cookie，不开启任意跨域 CORS。
- 请求体上限 64 KB；仅 HTTP(S) 标准端口。DNS 只接受公网 IPv4，拒绝私网及混合 DNS 答案并固定连接地址，每次重定向重新检查。仅 IPv6 资源当前不支持。
- 所有嵌套清单、分片、初始化段、AES-128 密钥都由同一校验下载器请求，密钥请求也检查公网地址、DNS、重定向、超时和体积限制。不导出浏览器会话，不破解密钥；密钥接口 401/403 时停止并提示刷新来源正常授权。
- 密钥仅在内存中按声明缓存，完成或失败时覆盖缓存 Buffer，不写文件或日志；密钥下载字节计入任务限额。分片解密并校验格式后才写入任务临时目录，离线清单移除 KEY/SESSION-KEY，并把分片、初始化段地址替换成本地文件名。FFmpeg 仅能用 file 协议读取本地媒体，命令参数不接收远端地址或密钥。保留的时长等元数据来自源清单，临时目录仍应视为私有数据。
- 子进程不使用 shell；文件名使用内部 UUID 和序号，日志与任务文件不保存签名、令牌或远端响应正文。
- 不要以 root 身份运行服务；媒体解析器应保持更新。需要处理不可信公共上传时，应进一步将 FFmpeg 隔离到无网络、只挂载单任务目录的容器中。本功能是管理员私用工具，不是公共视频代理。

## 测试

`npm run test:videos` 测试解析、AES-128 显式/隐式 IV、密钥轮换、错误密钥、SSRF URL 边界、资源限制、离线重写与模拟工具封装流程。`npm run test:videos:ffmpeg` 在已安装 FFmpeg / ffprobe 时生成本地合成加密样片，验证真实解密、封装和输出；未安装时跳过。`npm run build && npm run test:videos:runtime` 使用隔离目录测试真实 Next HTTP 接口、鉴权、配对、Range、重启恢复、文章视频保存/发布/安全渲染和 JSON 远端同步。OSS 单元测试仅使用模拟客户端，不真实上传。测试不访问实际文章视频，不改动现有数据。

AES-128 格式依据 [RFC 8216 §4.3.2.4](https://www.rfc-editor.org/rfc/rfc8216.html#section-4.3.2.4) 和 [§5](https://www.rfc-editor.org/rfc/rfc8216.html#section-5)。加密不等于 DRM；此实现仅兼容 identity 密钥，不处理许可证系统。

可使用 `VIDEO_IMPORT_DIR` 指定独立的私有存储目录（例如测试临时目录）；不要放到 public、Git 跟踪目录或其他服务共享目录中。
